# AutoElite Car Dealership

## Project Overview

AutoElite Car Dealership is a full-stack web application designed to manage vehicle inventory and customer purchases.

The application provides secure user authentication, vehicle browsing and searching, vehicle purchasing, stock management, and admin controls for managing dealership inventory.

The backend is built using Node.js, TypeScript, Express.js, Prisma, and SQLite, while the frontend is developed using React, TypeScript, and Vite. JWT is used for authentication and role-based authorization, bcrypt is used for secure password hashing, and database transactions are used to maintain consistency during vehicle purchases and stock updates.

---

## Features

### Customer Features

- User registration and login
- JWT-based authentication
- Secure password hashing using bcrypt
- View available vehicles
- Search vehicles
- Purchase vehicles
- Automatic stock reduction after purchase
- Prevention of purchases when stock is zero

### Admin Features

- Admin authentication and authorization
- Create vehicles
- View vehicles
- Search vehicles
- Update vehicle details
- Delete vehicles
- Restock vehicles
- Manage vehicle inventory
- Role-based access control

### Purchase & Transaction Features

- Stock validation before purchase
- Automatic stock update after purchase
- Zero-stock purchase prevention
- Database transactions for consistent purchase operations
